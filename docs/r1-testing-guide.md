# R1 端到端测试指南（网页端）

> 本文档提供 R1 Lab Pilot 的网页端手工测试流程。
> 按顺序执行，每一步记录结果（通过 / 失败 + 错误信息）。
> 测试前请准备一个有章节标题的中文 PDF 文件（10 页以内即可）。

---

## 0. 环境准备

### 0.1 启动 Docker 服务

```bash
docker compose -f infra/docker/docker-compose.yml --env-file infra/docker/.env up -d
```

确认三个服务运行正常（postgres / redis / minio 均为 healthy）。

### 0.2 启动后端 API

```bash
cd apps/api
conda activate DatasetGen
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

保持终端运行。

### 0.3 启动前端

```bash
cd apps/web
npm run dev
```

保持终端运行。

### 0.4 确认 MinIO 桶

浏览器访问 `http://localhost:9003`，用 `minioadmin` / `minioadmin123` 登录。
确认存在 `documents` 和 `outputs` 两个桶。如果不存在：

```bash
docker compose -f infra/docker/docker-compose.yml --env-file infra/docker/.env up minio-init
```

**结果：** [ ] 通过 / [ ] 失败

## 3. 配置模型（设置页）

> 后续 LLM 生成需要可用的模型配置。如果没有 LLM API 密钥，可跳过此步，但第 8-10 步将无法测试。

1. 点击顶部「设置」Tab
2. 默认显示第一个配置 Tab（模型配置）
3. 点击「新建」按钮
4. 填写表单：
   - 名称：`DeepSeek`
   - Provider：`openai`
   - Base URL：`https://api.deepseek.com/v1`（或你的 LLM 服务地址）
   - API Key：你的密钥
   - 模型名称：`deepseek-chat`
   - Temperature：`0.7`
   - Max Tokens：`2048`
5. 点击保存/创建
6. 确认列表中出现新建的模型配置
7. （可选）点击「测试连接」按钮，确认连通性

**预期：** 模型配置创建成功，列表中显示。测试连接返回成功。

**其他 Tab 快速检查：**
- 切换到「解析器」Tab → 应有 1 个默认配置"Mock 解析器（默认）"
- 切换到「切分」Tab → 应有 1 个默认配置"混合标题递归（默认）"
- 切换到「导出」Tab → 应有 1 个默认配置"SFT JSONL（默认）"
- 切换到「任务策略」Tab → 应有 1 个默认配置

**结果：** [ ] 通过 / [ ] 失败

## 4. 上传 PDF 文档

4. 再次上传同一个 PDF 文件

## 5. 文档解析

1. 在文档列表中点击刚上传的文档，进入文档详情页
2. 找到「发起解析」按钮，点击
3. 选择解析器配置（默认的 Mock 解析器）
4. 确认/提交

**预期：** 文档状态变为 `parsing`，随后自动变为 `parsed`（可能需要刷新页面）。

5. 检查文档详情中的解析任务列表，应有 1 个已完成的 ParseJob

**结果：** [ ] 通过 / [ ] 失败

## 6. 清洗工作台

### 6.1 开始清洗

1. 在文档详情页点击「开始清洗」按钮
2. 等待状态变为 `cleaning`

**预期：** 清洗任务创建成功，文档状态变为 `cleaning`。

### 6.2 进入清洗工作台

1. 点击「清洗工作台」按钮（或导航到 clean 页面）
2. 页面应显示四栏布局：
   - 左栏：PDF 预览
   - 中左栏：原始 Markdown（只读）
   - 中右栏：Markdown 编辑器（可编辑）
   - 右栏：预览 + 评论 + 审核操作
3. 左侧应有 Section 列表侧边栏

**预期：** 四栏布局正常显示，Section 列表中有从 PDF 解析出的章节。

### 6.3 编辑 Section

1. 在 Section 列表中点击第一个 Section
2. 中左栏显示原始 Markdown
3. 在中右栏编辑器中修改内容（随意修改几个字）

**预期：** 编辑器可正常输入，右栏预览实时更新。

### 6.4 提交审核

1. 点击「提交审核」按钮

**预期：** Section 状态变为 `review_pending`。

### 6.5 审核通过

1. 点击「通过」按钮

**预期：** Section 状态变为 `accepted`。

### 6.6 批量处理其余 Section

> 切分操作只处理 accepted 状态的 Section。需要把所有 Section 都审核通过。

1. 逐个点击剩余 Section → 提交审核 → 通过
2. 确认所有 Section 状态均为 `accepted`

**结果：** [ ] 通过 / [ ] 失败

## 7. 切分 (Chunking)

1. 返回文档详情页
2. 点击「执行切分」按钮
3. 选择切分配置（默认的"混合标题递归"）
4. 确认/提交

**预期：** 文档状态变为 `chunking`，随后变为 `chunked`。

5. 点击进入 Chunk 列表页
6. 确认列表中有多个 Chunk，每个显示 heading_path、token_count、status: ready

**预期：** Chunk 列表非空，每个 Chunk 有内容和 token 计数。

**结果：** [ ] 通过 / [ ] 失败

## 8. LLM 生成

> **前置条件：** 步骤 3 已配置可用的 ModelConfig。如果没有 LLM 服务，跳过此步。

### 8.1 查看 Prompt 模板

1. 点击顶部「模板」Tab
2. 应看到 3 个种子模板，按 task_type 分组：
   - 知识抽取：知识点抽取（默认）
   - 问答生成：问答对生成（默认）
   - 评测用例：评测用例生成（默认）

**预期：** 3 个模板正常显示。

### 8.2 模板试跑（可选）

1. 点击"知识点抽取（默认）"模板，进入编辑页
2. 左侧显示 system prompt 和 user prompt 模板
3. 右侧选择一个 Chunk
4. 选择模型配置（步骤 3 创建的）
5. 点击「试跑」

**预期：** 右侧显示 LLM 返回结果（JSON 格式的知识点）、token 用量、耗时。

### 8.3 单 Chunk 生成

1. 返回 Chunk 列表，点击任一 Chunk 进入详情页
2. 在生成面板中：选择"知识点抽取"模板 + 模型配置
3. 点击「生成」

**预期：** 生成任务创建，Chunk 状态变为 `generating`，随后变为 `generated`。

### 8.4 批量生成

1. 返回文档详情页
2. 点击「批量生成」按钮
3. 选择模板 + 模型配置
4. 确认

**预期：** 批量生成任务创建，逐步处理所有 ready 状态的 Chunk。可在「任务」Tab 查看进度。

**结果：** [ ] 通过 / [ ] 失败 / [ ] 跳过（无 LLM）

## 9. 候选审核 + CuratedItem

> **前置条件：** 步骤 8 已完成（至少有 1 个 Candidate）。

### 9.1 查看候选列表

1. 点击顶部「候选」Tab
2. 应显示 LLM 生成的 Candidate 列表，状态为 `ai_generated`

**预期：** 列表非空，每条显示生成内容摘要和状态。

### 9.2 审核 Candidate

1. 点击某个 Candidate 展开审核面板
2. 查看生成的内容
3. 选择审核判定：`支持`（supported）
4. （可选）填写证据 span
5. 点击提交审核

**预期：** Candidate 状态变为 `approved`。

### 9.3 提升为 CuratedItem

1. 在已 approved 的 Candidate 上点击「提升为知识资产」

**预期：** 创建成功，跳转或提示成功。

### 9.4 查看 CuratedItem

1. 点击顶部「知识资产」Tab
2. 列表中应出现刚提升的条目

**预期：** CuratedItem 显示内容、状态、来源信息。

### 9.5 审批 CuratedItem

1. 点击进入 CuratedItem 详情
2. 如果状态为 `draft`，修改为 `approved`

**预期：** 状态更新成功。

**结果：** [ ] 通过 / [ ] 失败 / [ ] 跳过（无 LLM）

## 10. Dataset + 导出

> **前置条件：** 步骤 9 已完成（至少有 1 个 approved 的 CuratedItem）。

### 10.1 创建 Dataset

1. 点击顶部「数据集」Tab
2. 点击「新建」
3. 输入名称"测试数据集"
4. 确认创建

**预期：** Dataset 出现在列表中。

### 10.2 添加条目

1. 点击进入 Dataset 详情
2. 点击「添加条目」
3. 选择已 approved 的 CuratedItem
4. 确认添加

**预期：** 条目添加成功，列表中显示 1 条。

### 10.3 导出

1. 在 Dataset 详情页点击「导出」
2. 选择导出配置（默认的 SFT JSONL）
3. 确认导出

**预期：** 导出任务创建。

4. 等待导出完成后，点击「下载」

**预期：** 下载 .jsonl 文件，内容为合法的 JSON Lines 格式。
