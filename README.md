# domain-dataset-gen

压气机领域知识抽取与数据资产平台。目标是把 PDF 文献加工为可追溯、可审核、可复现的知识资产，并进一步编组成数据集与 benchmark。

## Current Status

- 当前处于 **R1 Lab Pilot 测试修复阶段**
- R1 初版实现已经完成，但不等于验收完成
- 已完成大量真实测试回灌修复，前半段链路相对稳定
- 仍待完成的 R1 验收重点：LLM 生成、审核→提升、导出端到端验证
